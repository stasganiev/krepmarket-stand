# КрепМаркет - учебная конфигурация 1С

Оптовый поставщик крепежа. Конфигурация 1С:Предприятие 8.3.27 на БСП 3.1.12 + торговое ядро (номенклатура, контрагенты, цены, остатки, заказы клиентов).

## Устройство
- `src/cf/` - конфигурация в XML (иерархическая выгрузка). Наш код - торговое ядро; объекты БСП (подсистема `СтандартныеПодсистемы`) меняем только через переопределяемые модули
- `scripts/` - работа с базой из командной строки, `fixtures/` - демо-данные, `docs/` - описание проекта

## Команды (PowerShell, из корня репозитория)
- `.\scripts\check.ps1` - загрузить изменения в базу и выполнить синтакс-контроль. Ошибки - в `logs/check.txt` в формате `путь.bsl:строка:колонка: текст`. Код выхода 0 - ошибок нет
- `.\scripts\dump.ps1` - выгрузить конфигурацию из базы в `src/cf` (только этим скриптом, не из меню Конфигуратора)
- `.\scripts\load.ps1` - полная загрузка `src/cf` в базу (после `git checkout` / `pull`)
- Код выхода 2 и «База занята» - открыт Конфигуратор: попроси человека закрыть его

## Коммиты
Conventional Commits: тип и область на английском, описание на русском в повелительном наклонении. Пример: `feat(orders): добавить пересчет суммы в заказе`
Области: `stand` - стенд, скрипты, БСП · `orders` - заказы клиентов · `counterparties` - контрагенты
