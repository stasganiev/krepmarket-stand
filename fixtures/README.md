# Демо-данные «КрепМаркет»

Справочные данные учебного стенда: оптовый поставщик крепежа. **Все данные вымышленные:** компании, люди, телефоны и ИНН придуманы, email - только в домене `.example`.

| Файл | Куда загружается | Записей |
|------|------------------|---------|
| `nomenclature.csv` | Справочник Номенклатура: Код; Артикул; Наименование; Группа; ЕдиницаИзмерения; ВУпаковке; УпаковокНаПаллете; Цена | 256 позиций, 14 групп |
| `counterparties.csv` | Справочник Контрагенты: Код; Наименование; ИНН; КПП; Email; Телефон; КонтактноеЛицо; Комментарий | 30 (из них 2 ИП) |
| `stock.csv` | Остатки: КодНоменклатуры; Количество | 256 строк, 214 с ненулевым остатком |
| `order_history.csv` | Заказы клиентов за 01.09-05.11.2026: НомерЗаказа; Дата; КодКонтрагента; КодНоменклатуры; Количество; Цена | 70 заказов, 324 строки |

## Формат

- UTF-8 **с BOM**, разделитель `;`, первая строка - заголовки (как имена реквизитов 1С), перевод строки CRLF
- Коды - строки с ведущими нулями (`00007`, `К-005`, `ЗК-00069`): не приводить к числу. Не открывай CSV в Excel с последующим сохранением - он съест ведущие нули
- Числа - с **точкой** как десятичным разделителем (`126.82`)
- Единица измерения - базовая: `шт`, `кг` (весовые гвозди), `пар` (перчатки, беруши). Цена - за базовую единицу
- У трех контрагентов в поле Email два адреса через `, ` (менеджер и бухгалтерия)
- Колонка `Комментарий` у контрагентов - пометки для людей, в базу не загружается

## Как загрузить

Загрузку пишет агент: обработка `ЗагрузкаДемоДанных` внутри конфигурации (урок 03 курса). Порядок: Номенклатура (группы-папки по колонке Группа) → Контрагенты → ЦеныНоменклатуры → документ ПоступлениеТоваров `ДЕМО-001` (остатки) → ЗаказКлиента по `order_history.csv` (строки с одним номером - один документ).

Цены и остатки - на **01.09.2026**, раньше первого заказа в истории. В регистр цен грузится текущий прайс из `nomenclature.csv`; цены в истории заказов за сентябрь примерно на 5 % ниже (с 01.10 прайс повышался) - это история, она хранится в самих заказах.

**Контрольные цифры после загрузки:** 256 номенклатуры, 14 групп; 30 контрагентов; 214 позиций с ненулевым остатком; 70 заказов с 324 строками.
