# КрепМаркет - учебный стенд курса «AI-арсенал 1С-разработчика» 2.0

Небольшая конфигурация оптового поставщика крепежа. На ней весь курс строится проект «Умный прием заказов»: письмо клиента → черновик заказа в 1С.

**Внутри:** платформа 8.3.27, БСП 3.1.12 (только нужные подсистемы), торговое ядро (номенклатура, контрагенты, цены, остатки, заказы клиентов), скрипты для работы с базой из командной строки, демо-данные.

> ⚠️ Черновик от 18.11.2026: стенд собирается. Разделы с пометкой «появится» заполнятся до старта курса.

## Что нужно заранее

- **Полная платформа 1С:Предприятие 8.3.27** (с Конфигуратором) и лицензия на нее
- **Git** для Windows
- **VS Code** + агент: Claude Code (трек A) или OpenCode (трек B) - установка в гайдах курса Г-3 и Г-4

## Развернуть за 15 минут

**1. Разрешить длинные пути в Git** (один раз на компьютере). Пути к некоторым файлам БСП длиннее 260 символов, без этой настройки клонирование оборвется:

```powershell
git config --global core.longpaths true
```

**2. Склонировать репозиторий** в короткий путь, например `C:\git\krepmarket-stand`:

```powershell
git clone <адрес репозитория - появится> C:\git\krepmarket-stand
cd C:\git\krepmarket-stand
```

**3. Разрешить запуск скриптов** (если PowerShell ругается на политику выполнения):

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**4. Создать базу:**

```powershell
.\scripts\new-ib.ps1
```

Скрипт сам найдет платформу 8.3.27, создаст файловую базу в папке `.ib` репозитория (в Git она не попадает) и загрузит в нее конфигурацию. Около 2 минут.

Хочешь базу в другом месте или другую платформу - скопируй `stand.local.example.json` в `stand.local.json` и поправь пути.

**5. Первый запуск:** добавь базу `.ib` в список баз 1С и открой ее в режиме 1С:Предприятие. БСП один раз выполнит начальное заполнение (около минуты).

**6. Загрузить демо-данные:** справочные данные лежат в `fixtures/` (описание - `fixtures/README.md`); обработка загрузки *появится после урока 03*.

**7. Проверить:**

```powershell
.\scripts\check.ps1
```

Ответ «Синтаксических ошибок нет» - стенд готов. Открой папку в VS Code и запусти агента.

## Скрипты

| Скрипт | Что делает | Когда |
|--------|-----------|-------|
| `scripts\check.ps1` | Загружает измененные модули в базу и выполняет синтакс-контроль. Ошибки - в `logs\check.txt`: `путь.bsl:строка:колонка: текст` | После каждой правки кода |
| `scripts\load.ps1` | Полная загрузка `src\cf` в базу | После `git pull`, `git checkout`, смены ветки |
| `scripts\dump.ps1` | Выгрузка базы в `src\cf` | После правок в Конфигураторе |
| `scripts\new-ib.ps1` | Новая база из `src\cf` | Первая установка; `-Force` - пересоздать |

Коды выхода: `0` - все хорошо, `1` - найдены синтаксические ошибки, `2` - сбой (база занята, нет платформы, ошибка загрузки).

**Важно:**
- Пока база открыта в Конфигураторе или 1С:Предприятии, скрипты работать не могут - закрой их. Скрипт скажет об этом прямо
- Выгружай конфигурацию только `dump.ps1`, не из меню Конфигуратора: скрипт всегда работает на русском языке, иначе часть макетов выгружается с английскими строками и в Git появляются ложные изменения
- `check.ps1` по умолчанию загружает только измененные модули (`.bsl`) - это секунды. Если изменилась структура (XML, новые или удаленные файлы), он сам делает полную загрузку. `-Full` - полная загрузка принудительно

## Устройство репозитория

```
src/cf/       конфигурация в XML (иерархическая выгрузка)
scripts/      работа с базой из командной строки
fixtures/     демо-данные: номенклатура, контрагенты, цены, остатки, история заказов
docs/         описание проекта (появится)
tools/        сборка стенда с нуля и служебные скрипты автора курса
AGENTS.md     правила проекта для агента (CLAUDE.md ссылается на него)
```

## Эталонные решения

Во время курса в репозитории появляются теги `etalon-k1` ... `etalon-k6` - эталонная реализация проекта к каждому чекпоинту. Тег публикуется после дедлайна чекпоинта:

```powershell
git fetch --tags
git diff start etalon-k1 --stat                    # что изменилось от старта до эталона
git worktree add ..\krepmarket-etalon-k1 etalon-k1  # эталон отдельной папкой рядом со своей работой
```

В репозитории только код и файлы проекта. Методические материалы курса (уроки, промпты, задания, разборы) - на платформе курса.
