# tools - сборка стенда с нуля

Для автора курса и для тех, кому интересно, как собран стенд. Ученику для работы эта папка не нужна.

| Файл | Что это |
|------|---------|
| `bsp_merge_settings.xml` | Настройки сравнения/объединения: какие подсистемы БСП 3.1.12 входят в стенд. Получены обработкой `ПервоеВнедрениеБСП.epf` из поставки БСП |
| `embed-bsp.ps1` | Пустая база → БСП по этим настройкам → снятие с поддержки → свойства конфигурации и модуль обновления → загрузка и синтакс-контроль. Около минуты |

## Состав БСП в стенде

Базовая функциональность · Обновление версии ИБ · Пользователи · Контактная информация · Работа с почтовыми сообщениями · Работа с файлами · Получение файлов из Интернета · Дополнительные отчеты и обработки + зависимости: Подключаемые команды, Настройка порядка элементов.

## Как пересобрать

```powershell
.\tools\embed-bsp.ps1 -IbPath C:\bases\krepmarket-bsp
```

Скрипт сам найдет поставку БСП 3.1.12 в каталоге шаблонов (`%APPDATA%\1C\1cv8\tmplts\1c\SSL\`); другая поставка - параметр `-LibraryCf`. Режим совместимости ставится как у БСП (`Version8_3_24`): файл настроек его не переносит. Макет «Что нового в версии» (`ОписаниеИзмененийСистемы`) скрипт берет из `src\cf` стенда.

**Если собираешь руками в Конфигураторе с английским интерфейсом:** пустая конфигурация получит язык `English`, и после объединения с БСП в ней окажутся два языка, а в макетах - английские слои. Стенд должен быть с одним языком `Русский` (код `ru`) - как у БСП. Скрипт создает базу с `Locale=ru_RU`, у него этой проблемы нет.

После сборки - один раз открыть базу в 1С:Предприятии (начальное заполнение) и выгрузить: `.\scripts\dump.ps1 -IbPath C:\bases\krepmarket-bsp`.

**Довнедрить подсистему:** снова открыть `ПервоеВнедрениеБСП.epf`, отметить нужное, сохранить настройки поверх `bsp_merge_settings.xml`, пересобрать. Торговое ядро и все, что сверху, переносится в новую сборку сравнением/объединением со старой конфигурацией.

Проверено 18.11.2026: платформа 8.3.27.2342, БСП 3.1.12.381 - сборка 50 с, синтакс-контроль без ошибок, первый запуск 1С:Предприятия - 18 обработчиков обновления без ошибок.
